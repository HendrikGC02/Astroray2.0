# 150 Half and float image textures (EXR and Radiance HDR)
Goal: images are 8-bit only and a 16-bit or EXR file renders magenta -> EXR (half or float, scanline or tiled, RGB, RGBA or Y) and Radiance .hdr files decode from FILE and MEMORY sources, are stored at source precision, and TEX_IMAGE reads them with Closest and Linear, Repeat and Extend identically on CPU and GPU. Half and float images are linear (no sRGB decode), count their real bytes in the textures ledger, and use the same upload path as 8-bit images. [lane kernel; Sonnet]
