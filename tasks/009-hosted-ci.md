Task 030 replaces this list by gate's `cpu`-tagged steps. Prints and stores the exact `cl` version in out/check/ci.json.
3. Until task 010 posts `astroray/gate`, the lead merges with an admin override and says so in the PR.
Acceptance: a pull request with this change shows a green `ci` check whose log contains `cl 19.44` or newer and `PASS ci`; `pwsh tools/check.ps1 ci` passes locally with `$env:CI='true'`; a pushed commit that breaks lint (throwaway branch) turns `ci` red.
