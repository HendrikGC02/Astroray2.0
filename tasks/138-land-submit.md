1. land.ps1 modes `prepare|merge|submit`. submit takes `PASS|SKIP`, `-Title` (default: the task file's title), `-Evidence text`, `-CiDeadlineMin` (default 45). ASTRORAY_DEPS_CACHE defaults to the main checkout's third_party/_cache when unset (derived from `git worktree list`, never a literal path). Refuse before any slow step when `Look at:` is not none and `-Evidence` is missing.
2. Start of prepare and submit: REFUSE `another land.ps1 is running (pid N, started T)` (command-line match, own process and ancestors excluded); REFUSE `out/bin/astroray_core.dll is loaded by <name> (pid N)` for this worktree's DLL (Process.Modules; a process that denies access is skipped). Nothing is killed.
3. prepare records HEAD before its "(land)" commit; any failure after it (push, gate, status post, exception) resets the branch to that sha (`git reset --hard`; the tree was clean) and prints `undid (land) commit`. The re-prepare detection stays as a second guard.
4. prepare order: rebase; canary (the build step of lib/canary.ps1 runs tools/scenes.py after each build, before items); when `git diff --name-only origin/main HEAD` lists `blender/` or `tests/blender/`, the Blender suites `check full` runs (api_surface, test_images, test_node_values; and each windowed gui_* only when the diff lists blender/astroray/viewport.py, present.py, engine.py, heatmap_draw.py or tests/blender/gui_*; list from Get-ArFullBlenderSuites) under the machine lock, refusing on a failure with suite name and log path; the rebuild; the gate.
5. submit: prepare; open the PR or reuse the open one (body `Task NNN. Landed through tools/land.ps1.`, the attribution line the old script wrote, timings added after the merge); comment `REVIEW PASS <sha>` or `REVIEW SKIP <sha> (O31)`; the `evidence:` comment when `-Evidence` is given; wait for hosted `ci` on that exact sha (run registers within 5 min, else close and reopen the PR once and allow 3 min more; completion until the deadline; a failed run is FAIL with its URL, no retry); merge with the existing checks; on `re-run prepare` go back to prepare, at most 3 attempts, then FAIL. `-DryRun` prints this plan. LEAD.md step 5 names submit.
6. After the squash is confirmed on origin/main print `PASS merge NNN squash <sha> on origin/main`, then clean up in landing.ps1 from the main checkout (cwd moved out of the worktree), each step tried 3 times 5 s apart: delete the remote branch, `git worktree unlock`, `git worktree remove -f -f`, `git branch -D` on the exact name found once in `git worktree list` (never a prefix match). Print `LEFTOVER: <what>; fix: <command>` for anything left and exit 0.
7. Timing: a stopwatch per phase (rebase, scenes, canary, blender_suites, gate, ci_wait, merge, lock_wait = sum of Enter-ArMachineLock waits, retries = count). Print one `timing:` line and `gate <s> s (<+d|-d> s against task NNN)` from the previous history line's gate_s (or `no earlier landing line`); append the table to the PR body (`gh pr edit`; failure is a printed warning); append one JSON line {task, sha, date, verdict, attempts, rebase_s, scenes_s, canary_s, blender_suites_s, gate_s, ci_wait_s, merge_s, lock_wait_s} to out/land/history.jsonl of the MAIN checkout (the worktree's out/ is deleted).
