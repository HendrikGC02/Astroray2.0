# 146 Constant folding: the compiler's fold is table-driven and checked per opcode against the interpreter
Goal: the compiler already folds six ops (CONST_F32, CONST_F32X3, MUL_F32, MUL_F32X3, MUL_F32X3_F32, ADD_F32X3) through a hand-written switch in compiler.cpp `fold()`, `vm/fold equals interpret` checks the op functions only (not the compiler's fold), and nothing says which ops read context -> `ops.def` carries one `foldable` flag per row, `fold()` takes its eligibility from that flag and fails loudly for a foldable op it cannot evaluate, and a test generated from the op table compares the compiler's folded constant with the interpreter bit for bit on 1e4 random inputs per foldable op, so a new op is covered or refused with no test edit (0005 Verification 6, first clause).
