# Mesh read (0007 d17, d35 remedy 1; sync/mesh.py): direct reads, one memmove per array from element 0's
# as_pointer(). The names below are checked here; the pointer assumptions in the comments are checked by
# sync/mesh.py _copy (stride, contiguity to the last element, first and last values against these RNA properties)
# on the first read of each geometry key and again when a full read finds changed counts (the check guards layout
# not values; mesh.LayoutChecks; the attribute type and domain lookup runs on every read); a mismatch raises
# naming the array and the Blender version. `.corner_vert` is internal and may be
# renamed: the read then fails loudly (no fallback). Blender 5.3 storage behind each pointer (DNA_mesh_types.h,

#   attributes['position'].data[i].as_pointer()      -> float32 x3 per vertex, contiguous    (FLOAT_VECTOR, POINT)

#   corner_normals[i].as_pointer()                   -> float32 x3 per corner, contiguous
#   attributes[<uv map>].data[i].as_pointer()        -> float32 x2 per corner, contiguous    (FLOAT2, CORNER)
