# tools/

Scripts print at most 20 lines, log to out/check/, exit non-zero on failure (0009 d8, d9).

- build.ps1: configure if needed, build, prove no work is left; machine + tree lock, -NoMachineLock for CPU-only callers.
- lib/lock.ps1: Enter/Exit-ArMachineLock (Global\astroray2, nested via ASTRORAY_LOCK_PID), Enter/Exit-ArTreeLock <dir>.
- lib/summary.ps1: Start-ArSummary, Add-ArStep, Complete-ArSummary: 20-line summary plus out/check/<tier>.log and .json.
- lib/proc.ps1: Start-ArProcess (writes out/pids/<name>.pid), Stop-ArProcess -Id. No kill by name.
- lib/python.ps1: Get-ArPython: Blender 5.3 bundled python (python on CI); callers pass -I.
- lib/blender.ps1: Invoke-ArBlender -Script -Args -TimeoutS: isolated profile, machine lock, returns exit code and log.
- lint.py: SPDX, NVIDIA, ASCII ps1, process caps, skip/xfail, task-file format; `--self-test` runs tests/cpu/lint_cases/.
- budgets.toml: machine copy of 0009 d13 (B-01..B-37) and the d15 family sizes; lint section `budgets` checks it.
- check.ps1 fast: lint, `build.ps1 -Target astroray_tests_cpu -NoMachineLock -Jobs 4`, fast tests; fails on B-08 (tier) or B-12 (one test). No machine lock. check.ps1 ci (hosted CI, `.github/workflows/ci.yml`): fast, `build.ps1 -Preset cpu`, `fetch.ps1 deps`, `--tier=gate` tests, tests/abi unittests; prints the `cl` version and stores it in out/check/ci.json. The test exe uses the precompiled header tests/cpu/pch.h (doctest and std headers only, so the AR_REAL_DOUBLE wrapper TUs share it; main.cpp skips it). build.ps1 -Jobs n passes -j n.
- check.ps1 gate [-Declared spec] (machine lock; B-09 180 s, kernel part 120 s): fast, build dev + nofma, kernelgate self-test and resource gate, compile timing, tests/abi, dumpbin /dependents, `--tier=gate` tests on CPU and GPU. Every gate step is tagged `cpu` or `local` in check.ps1's `$gateSteps`; `ci` runs the `cpu` ones. check.ps1 full: gate plus the probe build (uncapped registers warn at 150, loudly above 168, never fail).
- kernelgate.py: `cuobjdump -res-usage` + ptxas -v of out/build/kernels/*.cubin against src/kernel/launch_config.h (T, B, k, stack class) and budget.toml (regs, stack, spills, compile_s, gated); `--full` (also the rows gated full; the gate prints how many it deferred), `--time` (B-05, changed TUs), `--probe`, `--self-test` (tests/budgets/kernelgate_cases/), `--declared`.
- report.py: offline out/report/index.html (tier durations vs B-08..B-11, build times, empty sections for later plots) from bench/history/*.jsonl and out/check/*.json; `--selftest`. History line keys: sha, machine, driver, cuda, scene, metric, value, unit, n, spread, date; lint section `history` checks them. bench/scenes.toml lists B scenes.
- deps/build_embree.ps1: recorded Embree 4.4.1 build (static, no TBB, /MT) into out/deps/embree-4.4.1-astroray-win64-mt.zip; machine lock; never called by build or check.
- deps/build_oidn.ps1: recorded OIDN 2.5.0 build (astroray_oidn*, /MT, static oneTBB 2022.3.0 in the CPU device, CUDA device) into out/deps/oidn-2.5.0-astroray-win64-mt.zip; prints dumpbin and CPU/CUDA smoke results; machine lock; never called by build or check.
- fetch.ps1 deps: downloads the fetched-* entries of third_party/deps.toml into third_party/_cache/<name>-<version>/, verifies SHA-256, extracts; thirdparty.py renders THIRD_PARTY.md from it (lint section `deps` checks both, `.github/ci-requirements.txt` and the D9.1 closed list). cmake/deps.cmake resolves the cache paths, no network.
- fetch.ps1 assets [-Name n]: downloads assets/manifest.toml entries into assets/_cache/<name>/, verifies SHA-256 and a non-empty spdx; names only, no crawl. Lint section `assets`: tests/data + scenes <= 50 MB, files <= 2 MB, committed assets licensed CC0/CC-BY/MIT/Apache-2.0, PNGs <= 2 MB and <= 1600 px (0009 d21).
- lib/blender.ps1 Invoke-ArBlenderCommand -Args: `blender --command ...` under the machine lock (used by the astroray_extension target).
- land.ps1 prepare|merge NNN [-DryRun]: lead only (0009 d26). prepare: branch/tree checks, rebase, canary verification, out/land/NNN/{task.md,diff.patch}, deletion commit, push, `check gate` posted as `astroray/gate`. merge: PR head == gated sha, `ci` and gate success, lead `REVIEW PASS <sha>` or `REVIEW SKIP <sha> (O31)`, `evidence:` comment, squash, cleanup. tests/tools/land_fixture/run_cases.ps1 runs the four fixture cases.
- status.ps1: task branches, open PRs with `ci`/`astroray/gate`, worktrees, last out/check summaries (<= 20 lines).
- tests/tools/fault_stress.ps1 -Runs n -Parallel p: runs the fault tests n times in each of p parallel loops (20 s timeout per run), prints `runs= hangs= failures=`, non-zero on any hang or failure. Not in any tier; needs minutes. The fault filter writes dumps through out/bin/astroray_dump.exe (src/dump/main.cpp), staged beside astroray_core.dll.
